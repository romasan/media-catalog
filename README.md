# Media Catalog

Нативное десктопное приложение для каталогизации фото и видео: **C++20 + Qt 6
(Qt Quick)**. Один код собирается под macOS, Windows и Linux.

> Ветка `native` — нативная реализация проекта. Прежняя версия на Electron +
> React осталась в ветке `main`; исходников Electron в этой ветке нет.

## Возможности

- 📁 **Управление каталогами** — добавление и удаление папок для сканирования;
  обход рекурсивный, включая дочерние папки; по каждому каталогу видно число фото
  и видео
- ⚡ **Автоматическое сканирование** — при запуске, после добавления каталога и по
  требованию; с уведомлением о добавленных и удалённых файлах
- 🖼️ **Адаптивная сетка превью** — квадратные карточки от 100 до 200 px,
  виртуализация: создаются только видимые ячейки, поэтому прокрутка остаётся
  плавной на больших каталогах
- 🗓️ **Диапазон дат видимых карточек** — метка в правом верхнем углу с меняющейся
  детализацией (день → месяц → год)
- 🎬 **Полноэкранный просмотр** — фото и видео, навигация клавишами, информация о
  файле, теги, воспроизведение видео со звуком
- 📅 **Дата съёмки из метаданных** — EXIF для фото и `creation_time` для видео;
  показывается, если отличается от даты изменения файла
- 📂 **Показать в проводнике** — ПКМ по медиа в просмотре открывает Finder или
  Проводник с выделенным файлом (сам файл не открывается)
- 🏷️ **Теги** — создание, поиск, автодополнение, массовое присвоение выделенным
  файлам, менеджер тегов с числом применений
- 🏷️ **Метатеги** — автоматические теги (год, время года, тип файла, «без тега»);
  не хранятся в базе, не экспортируются, показываются серым
- 🔍 **Фильтрация** — режимы «все» (И) и «любой» (ИЛИ), счётчик видимых файлов
- 🖼️ **Генерация превью** — через ffmpeg, пул процессов по числу ядер, прогресс,
  продолжение очереди после перезапуска
- 💾 **Экспорт/импорт данных** — перенос каталогов, тегов и связей между
  устройствами
- 🔒 **Без сети** — приложение не открывает портов и не требует интернета

## Быстрый старт

```bash
# macOS
brew install cmake ninja qt ffmpeg

cmake -S . -B cmake-build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build cmake-build
open cmake-build/mediacatalog.app
```

Инструкции для Windows и Linux, сборка пакетов и решение проблем — в
[docs/BUILD.md](docs/BUILD.md).

Полезные ключи:

```bash
./mediacatalog --data-dir /path/to/data   # свой каталог данных
./mediacatalog --help
```

## Тесты

```bash
cd cmake-build
ctest --output-on-failure
```

| Набор | Что проверяет |
|-------|---------------|
| `mc_core_tests` | Ядро: хэш имён превью (сверка с эталонами версии 1.x), форматы, метатеги, разбор EXIF, база данных, фильтрация, сканирование, генерация превью, экспорт/импорт |
| `mc_model_tests` | Путь «файлы на диске → сканирование → превью → данные для QML»: модели, доставка превью, теги, режимы фильтра, выделение |

## Как это работает

1. Пользователь добавляет папки — приложение рекурсивно сканирует их и находит
   фото и видео; каждый файл приписывается самому глубокому добавленному каталогу.
2. Для каждого нового файла в фоне генерируется превью 400×400 через ffmpeg.
   Одновременно работают столько процессов, сколько ядер у процессора.
3. Файлы просматриваются в полноэкранном режиме, им присваиваются теги, сетка
   фильтруется по тегам и метатегам в режимах «все» и «любой».
4. Метаданные хранятся в SQLite; экспорт и импорт переносят каталоги, теги и
   связи между устройствами.

Детали — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md),
[docs/DATA.md](docs/DATA.md) и [docs/WORKFLOW.md](docs/WORKFLOW.md).

> При любых изменениях кода сверяйтесь с [CLAUDE.md](CLAUDE.md) — документация и
> `CHANGELOG.md` должны обновляться в том же наборе изменений.

## Технологии

- **C++20** — язык реализации ядра и слоя приложения
- **Qt 6.5+** — Qt Quick (QML) для интерфейса, Qt Multimedia для видео,
  QtSql для доступа к SQLite
- **SQLite** (режим WAL) — хранилище каталогов, файлов, тегов и связей
- **ffmpeg / ffprobe** — генерация превью и чтение даты съёмки видео
- **CMake + Ninja** — сборка; **CPack** — DMG, NSIS-установщик, TGZ/DEB
- **Собственный EXIF-парсер** — дата съёмки фото без внешних библиотек
