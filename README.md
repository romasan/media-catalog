# Media Catalog

Десктопное приложение для каталогизации фото и видео, построенное на **Electron + React + TypeScript**.

## Возможности

- 📁 **Управление каталогами** — добавление/удаление папок для сканирования медиафайлов (рекурсивно, включая дочерние папки)
- 🖼️ **Адаптивная сетка превью** — квадратные карточки от 100×100 до 200×200 px, виртуализация для плавного скролла
- 🎬 **Полноэкранный просмотр** — фото и видео, навигация стрелками ←/→, информация о файле (путь, дата, размер)
- 🏷️ **Теги** — создание, поиск, применение к файлам, автодополнение при вводе
- 🏷️ **Метатеги** — автоматические теги (год, время года, тип файла), не хранятся в БД, не экспортируются, отображаются серым цветом, добавляются в фильтр кликом
- 🔍 **Фильтрация по тегам** — режимы «все» (AND) и «любой» (OR), добавление тега в фильтр из просмотра или менеджера тегов
- ⚡ **Автоматическое сканирование** — при запуске и при изменении списка каталогов, с уведомлением о добавленных/удалённых файлах
- 💾 **Экспорт/импорт данных** — перенос каталогов, тегов и связей между устройствами
- 🖼️ **Генерация превью** — через ffmpeg, с прогресс-баром (превью хранятся отдельно от исходников)

## Быстрый старт

```bash
npm install       # установка зависимостей
npm run dev       # запуск в режиме разработки (Electron + Vite + watch-компиляция)
```

## Сборка и дистрибуция

```bash
npm run build          # компиляция main/preload/renderer в dist/
npm run start          # сборка и запуск
npm run dist           # сборка установщика для текущей ОС
npm run dist:mac       # сборка DMG для macOS
npm run dist:win       # сборка NSIS-установщика для Windows
npm run dist:linux     # сборка AppImage для Linux
npm run typecheck      # проверка типов main и preload
```

## Как это работает

Приложение — это **Electron-десктоп** с тремя уровнями: main-процесс (Node.js: база данных, сканирование ФС, генерация превью), preload-мост (`window.api` через `contextBridge`) и React-renderer (интерфейс).

Основной сценарий:

1. Пользователь добавляет папки (каталоги) — приложение рекурсивно сканирует их и находит фото/видео.
2. Для каждого нового файла асинхронно генерируется превью 400×400 через ffmpeg (кэшируются в `media-catalog-data/thumbnails/`).
3. Файлы можно просматривать в полноэкранном режиме, присваивать им теги и фильтровать сетку по тегам (режимы «все»/«любой», ранее AND/OR).
4. Все метаданные хранятся в JSON-базе `catalog.db`; экспорт/импорт переносит каталоги, теги и связи между устройствами.

Детали — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/DATA.md](docs/DATA.md) и [docs/WORKFLOW.md](docs/WORKFLOW.md).

> При любых изменениях кода сверяйтесь с [CLAUDE.md](CLAUDE.md) — Cline обязан поддерживать документацию в актуальном состоянии.

## Технологии

- **Electron** 30 — десктопная оболочка
- **React** 18 — пользовательский интерфейс
- **Vite** 5 — сборка renderer-части (HMR в dev)
- **TypeScript** 5 — типизация всех процессов
- **ffmpeg-static** — нативный бинарник ffmpeg для генерации превью
- **electron-builder** — сборка установщиков (macOS/Windows/Linux)
