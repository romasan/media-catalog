# Сценарии работы

## Запуск

Приложение открывает каталог данных, подключается к базе и показывает окно. Если
каталоги уже добавлены, сразу запускается фоновое сканирование: в шапке видно
«Сканирование…», а на сетке — сообщение о ходе работы. Когда находятся новые
файлы, внизу появляется уведомление с их числом.

## Добавление каталога

1. Круглая кнопка меню в **правом нижнем углу** → **Управление каталогами**.
2. Кнопка **Добавить папку…** открывает системный диалог выбора папки.
3. Сразу после выбора запускается сканирование: папка обходится рекурсивно,
   включая все дочерние папки.

Что важно знать:

- Скрытые папки, `@eaDir` и `System Volume Information` пропускаются.
- Поддерживаются `jpg`, `jpeg`, `png`, `gif`, `webp`, `bmp`, `tiff`, `tif`,
  `heic`, `mp4`, `mov`, `avi`, `mkv`, `webm`, `m4v`.
- Если добавить папку, вложенную в уже добавленную, файлы не продублируются:
  каждый файл принадлежит самому глубокому каталогу, который его содержит.
- Повторное добавление той же папки ничего не меняет.

В окне **Каталоги…** по каждому каталогу видно число найденных фото и видео, а
рядом есть кнопка удаления. Удаление убирает каталог из списка и снимает теги с
его файлов, **сами файлы на диске не трогаются**.

## Сканирование

Сканирование запускается:

- при старте приложения, если каталоги уже добавлены;
- после добавления каталога;
- вручную — меню **Сканировать заново** или кнопкой в окне каталогов.

Во время работы приложение продолжает отвечать на действия: сканирование идёт в
отдельном потоке. По завершении показывается уведомление вида
«Добавлено файлов: 12, Удалено файлов: 3».

Правила синхронизации:

- новый файл → появляется в базе и ставится в очередь на превью;
- изменился размер или дата изменения → запись обновляется;
- файл исчез с диска → запись удаляется вместе со связями тегов, а его превью
  стирается.

## Генерация превью

Превью создаются автоматически сразу после сканирования.

- Одновременно работают столько процессов ffmpeg, сколько ядер у процессора,
  поэтому загрузка распределяется, но система не перегружается.
- Полоса под шапкой показывает долю готовых превью; в шапке — процент.
- Готовое превью появляется в сетке сразу, без перезагрузки списка: позиция
  прокрутки сохраняется.
- Для видео берётся кадр на 0.5-й секунде; значок ▶ на карточке отмечает видео.
- Если файл повреждён, попытка повторяется один раз, после чего файл остаётся
  с заглушкой.
- Если приложение закрыли во время генерации, при следующем запуске очередь
  продолжается с того же места.

## Просмотр в сетке

Сетка показывает превью квадратными карточками. Размер карточки подбирается под
ширину окна: от 100 до 200 пикселей, — так, чтобы карточки заполняли всю ширину.

В правом верхнем углу сетки — метка с диапазоном дат изменения файлов, попавших
в видимую область. Детализация подстраивается под диапазон:

| Диапазон | Пример |
|----------|--------|
| Один день | `22 апреля 2025` |
| Один месяц | `1–9 мая 2025` |
| Один год | `июн – июл 2025` |
| Разные годы | `2024 – 2026` |

## Выделение файлов

| Действие | Результат |
|----------|-----------|
| Обычный клик | Открывает полноэкранный просмотр |
| Ctrl/Cmd + клик | Добавляет файл к выделению или снимает его |
| Shift + клик | Выделяет диапазон от последней карточки, выбранной через Ctrl/Cmd |
| Клик по пустому месту | Снимает выделение |

При выделении снизу появляется панель с числом выбранных файлов, кнопками
**Снять выделение** и **Выделить все**.

## Полноэкранный просмотр

Открывается обычным кликом по карточке.

| Клавиша / действие | Результат |
|--------------------|-----------|
| `←`, клик по левой половине | Предыдущий файл |
| `→`, `Пробел`, клик по правой половине | Следующий файл |
| `Home` / `End` | Первый / последний файл списка |
| `Esc`, `Backspace`, двойной клик | Выход в сетку |
| ПКМ | Контекстное меню |

В левом верхнем углу — имя файла, путь, дата изменения, размер и теги. Если из
метаданных известна дата съёмки и она отличается от даты изменения файла, она
показывается отдельно («съёмка: …»). Справа сверху — позиция в списке.

Контекстное меню файла:

- **Показать в проводнике** — открывает Finder (macOS) или Проводник (Windows) с
  выделенным файлом;
- **Добавить тег…** — открывает менеджер тегов для этого файла;
- **Добавить метатег в фильтр** — сразу добавляет год, сезон и тип файла в фильтр.

Видео воспроизводится прямо в просмотре, циклически, со звуком.

## Теги

### Присвоение тега файлу

1. Открыть файл в полноэкранном просмотре.
2. ПКМ → **Добавить тег…**
3. Ввести имя в поле поиска. Если тега нет — нажать **Создать**.
4. Клик по тегу в списке применяет его, повторный клик — снимает. Уже
   применённые теги отмечены галочкой.

### Массовое тегирование

1. Выделить нужные файлы (Ctrl/Cmd и Shift + клик).
2. В нижней панели ввести имя тега и нажать **Применить** — тег получит сразу
   весь набор выделенных файлов.

### Менеджер тегов

Открывается из меню → **Управление тегами** или кнопкой в панели массового тегирования.

Попапы (каталоги и теги) закрываются крестиком в заголовке, клавишей `Esc` или
кликом по затемнённому фону.

- Список всех тегов с числом применений.
- Поиск по подстроке.
- **Создать** добавляет новый тег.
- Двойной клик по тегу в режиме файла применяет или снимает его.
- **Удалить тег** (с подтверждением) убирает тег и снимает его со всех файлов.
- В заголовке показано общее количество тегов.

Имена тегов нормализуются: лишние пробелы убираются, регистр приводится к
нижнему. «Отпуск» и «отпуск» — один и тот же тег.

## Метатеги

Метатеги вычисляются автоматически и в базе не хранятся: год, время года, тип
файла и «без тега». В интерфейсе они показываются серым, чтобы отличаться от
пользовательских тегов.

- Клик по метатегу в фильтре добавляет его к условиям.
- Метатег **«без тега»** взаимоисключающий с обычными тегами: при его добавлении
  пользовательские теги из фильтра убираются, и наоборот.
- Метатеги не экспортируются: после импорта они пересчитываются.

## Фильтрация

Панель фильтра — компактная плашка в **левом нижнем углу**, всегда на экране.

1. Добавить теги или метатеги в фильтр (из просмотра, менеджера тегов или кликом
   по метатегу).
2. При двух и более выбранных тегах сверху появляется переключатель режима:
   - **все** — файл должен удовлетворять всем условиям;
   - **любой** — достаточно одного условия.
3. Справа в строке — счётчик: сколько фото и видео в текущей выдаче. При пустом
   фильтре это количество по всему каталогу, при активном — с учётом фильтра.
4. Крестик на чипе убирает отдельное условие.

Если фильтр пуст, панель показывает только счётчик — как в версии 1.x.

## Экспорт и импорт

**Экспорт.** Меню → **Экспорт**, выбрать файл `.json`. Сохраняются
каталоги, теги и связи тегов с файлами.

**Импорт.** Меню → **Импорт**, выбрать ранее сохранённый файл. После
импорта приложение добавляет каталоги, создаёт отсутствующие теги, восстанавливает
связи и запускает сканирование.

Связи восстанавливаются по путям файлов и именам тегов, поэтому перенос работает
и на другое устройство, где идентификаторы файлов отличаются. Подробнее о формате —
в [DATA.md](DATA.md).

## Уведомления

В правом нижнем углу появляются всплывающие сообщения: результат сканирования,
применение тега к группе файлов, итог экспорта или импорта, ошибки. Сообщение
исчезает само через 4 секунды, но его можно закрыть кликом.
